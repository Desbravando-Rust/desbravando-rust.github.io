01 / Destaques

Feito para o dia a dia com banco de verdade

Tudo que a v1 entrega, sem plugin e sem conta.

  • Conexões seguras

    TLS 1.2+ via rustls (de disable a verify-full) e túnel SSH com senha, chave ou agent, checando known_hosts.

  • Senhas no keyring do sistema

    Sem keyring, o app pergunta a cada conexão. Nenhuma senha vai para o disco.

  • Árvore de objetos sob demanda

    Bancos, schemas, tabelas, views, funções e triggers carregados só quando você abre.

  • Grid virtualizado

    Paginação, ordenação, filtros parametrizados e visão de estrutura e DDL de cada tabela.

  • Editor SQL completo

    Highlight, autocomplete, cancelamento de query, histórico e arquivos .sql. Begin, Commit e Rollback à mão.

  • Proteção contra o DELETE sem WHERE

    Comandos destrutivos pedem confirmação. Exportação CSV em streaming e cancelável.

Compilar do código-fonte

O rustup instala a toolchain fixada em rust-toolchain.toml.

bash 
$ sudo apt-get install -y libxkbcommon-dev libwayland-dev
$ git clone {{ cr.repo }}.git
$ cd crustdb
$ cargo build --release
$ cargo run -p crustdb-app

Requer Linux x86_64 e rustup.
